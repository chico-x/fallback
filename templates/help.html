Click any step to copy instructions to clipboard

Issuing a New Certificate

  1. Navigate to the "Issue Certificate" interface.
  2. Provide a unique Certificate Identifier (e.g. CERT-2026-ETH-001).
  3. Upload the document file (PDF, JPG, or PNG format).
  4. Review SHA-256 client-side hash computation.
  5. Confirm the transaction in your MetaMask wallet on Sepolia.
  6. Save the returned Ethereum transaction hash for audit records.
2

Verifying an Issued Document

  1. Open the "Verify Certificate" interface.
  2. Type in the target Certificate ID.
  3. Upload the physical or digital document file to evaluate.
  4. The system calculates the document hash and queries the blockchain record.
  5. Match validation and visual AI forensics are generated automatically.
